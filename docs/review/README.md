# Lesson review pages

Student-facing review pages use these conventions (Kiyoko, 25 October 2026):

- Give Japanese example sentences and their English meanings separate spans.
- Provide independent Hide Japanese / Show Japanese and Hide English / Show English buttons.
- Start with both languages visible. Both hidden is also supported.
- Use English for the controls and practice instructions so beginning Japanese learners can use them.
- Practice instruction: “Let’s see how much you remember! Hide one language and give it a try.”
- Use Vocabulary practice for the vocabulary link; omit NCEA labels and next-lesson date/time notices.
- Keep the lesson content, existing links and conversation answer reveals intact.
- Match the implemented pattern in 2026-10-03/index.html; for pages with examples in several sections, see 2026-10-25/index.html.

These are local authoring conventions. Publishing still requires authorization.
